# 🔗 LinkPulse — Custom Link-in-Bio & Real-Time Analytics Hub

A lightweight, fast, and fully customizable Link-in-Bio application with built-in real-time click tracking analytics. Designed as a self-hosted alternative to subscription tools like Linktree or Beacons.

---

## ✨ Key Features
* 📊 **Real-Time Click Tracking**: Monitor total profile views and individual link clicks instantly.
* 🎨 **Custom Profile Styling**: Easily customize avatar image, name, bio description, and social media links.
* ⚡ **Fast & Lightweight**: Built with pure HTML5, CSS3, and Vanilla JavaScript—zero build steps or heavy dependencies.
* 💾 **Local Data Persistence**: Stores link data and click counts locally using browser LocalStorage.
* 📱 **Fully Responsive**: Clean, modern dark-mode interface optimized for mobile, tablet, and desktop screens.

---

## 🛠 Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Data Storage**: Browser LocalStorage
* **Hosting**: Vercel / Netlify / GitHub Pages
